# airpact

This repository contains information and files that pertain to the long-term development of the AIRPACT-Air quality forecasting for the Pacific Northwest-modeling system at Washington State University. Visit [AIRPACT](https://airpact.wsu.edu/) to learn more. 

The AIRPACT forecast model results can be viewed at: [http://lar.wsu.edu/airpact/index.html. ](https://airpact.wsu.edu/map.html?v=0.003)

Questions regarding the model or its output can be directed to Dr. Jun Meng (jun.meng@wsu.edu) and Dr. Von P. Walden (v.walden@wsu.edu).
